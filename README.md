# 🏦 Bank Customer Churn Prediction using Machine Learning & Artificial Neural Network

## 📌 Project Overview

This project predicts whether a bank customer is likely to leave (churn) within the next six months using customer information such as credit score, geography, gender, age, balance, and account activity.

Three classification models—**Logistic Regression**, **Random Forest Classifier**, and **Artificial Neural Network (ANN)**—are implemented and compared to determine the best-performing model.

---

## 🎯 Objective

The main objectives of this project are to:

- Read and explore the dataset.
- Clean and preprocess the data.
- Perform Exploratory Data Analysis (EDA).
- Build Logistic Regression, Random Forest, and ANN models.
- Evaluate and compare the models using multiple performance metrics.
- Identify the best-performing model for customer churn prediction.

---

## 🏆 Results

All three models were trained and evaluated on the processed dataset.

Among the three models, **Random Forest Classifier** achieved the best performance with an **accuracy of 86.6% (0.866)**, outperforming both Logistic Regression and the Artificial Neural Network.
